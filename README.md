> ⚠️ The snake animation renders automatically **once you add the GitHub Action below** to a repo named exactly `NagadeepReddy` (a "profile repo"). It regenerates daily from your real contribution graph — genuine motion driven by your actual commit history.

<details>
<summary>📄 Click to expand: <code>.github/workflows/snake.yml</code></summary>

```yaml
name: Generate Snake Animation

on:
  schedule:
    - cron: "0 */6 * * *"   # every 6 hours
  workflow_dispatch: {}
  push:
    branches: [ main ]

jobs:
  generate:
    permissions:
      contents: write
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk@v3
        with:
          github_user_name: NagadeepReddy
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark

      - uses: actions/upload-artifact@v4
        with:
          name: github-contribution-grid-snake.svg
          path: dist/github-contribution-grid-snake.svg

      - uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```
