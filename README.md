`Python` · `Seldon Core` · `Docker` · `Kubernetes` · `GitHub Actions` · `AWS EKS`

`Helm` · `Kubernetes` · `NetworkPolicy` · `cert-manager` · `GitOps`
> Focus: platform engineering with security and scalability built in, not bolted on.
